## Project Objective
Create a clean, responsive personal portfolio with a Home page for my introduction, education, and relevant skills; a Projects page for detailed work and interactive project cards; and an AI-generated Contact page using only vanilla HTML5, CSS3, and ES6 modules.

## Pages
- `index.html` — brief introduction, education, and relevant skills
- `projects.html` — project details, skills used, and interactive hover cards
- `contact.html` — AI-generated contact page

## Design
The site uses a white background, green navigation/actions, restrained typography, responsive CSS Grid/Flexbox, and accessible semantic HTML. The original “Project Signal” component filters projects by technical theme.

## Profile Photo
Replace `images/profile-photo-placeholder.jpg` with your own image. Keep the same filename, or update the `src` in `index.html`.

## Run locally
1. Install Node.js.
2. Run `npm install`.
3. Run `npm start`.
4. Open the local URL shown by the server.

## Formatting and linting
- `npm run format`
- `npm run format:check`
- `npm run lint`

## Deployment
This is a static site and can be deployed using GitHub Pages, Netlify, Vercel, or another static hosting provider.
